## 使用指南

### 执行部署
```bash
cd /Users/lisheng/Code/quantsystem/quant_research_system/backend

# 1. 查看部署检查清单
cat docs/DEPLOYMENT_CHECKLIST.md

# 2. 执行部署（DRY RUN 模式）
DRY_RUN=true bash scripts/deploy/deploy.sh

# 3. 执行实际部署
bash scripts/deploy/deploy.sh

# 4. 健康检查
bash scripts/deploy/health_check.sh

# 5. 冒烟测试
bash scripts/deploy/smoke_test.sh
```

### 执行回滚
```bash
# 回滚到最新备份
bash scripts/deploy/rollback.sh

# 回滚到指定备份
bash scripts/deploy/rollback.sh 20260307_020000
```

### 数据库迁移
```bash
# 执行迁移
python database/migrations/v2.0/migrate.py

# 执行回滚
python database/migrations/v2.0/rollback.py
```
